# KotobaPlay

A Windows companion for learning Japanese with clickable Stremio subtitles.

**[Visit the website](https://mythices.github.io/kotobaplay/)**

Hiragana-first subtitles, optional romaji, offline word meanings, online pronunciation, estimated word highlighting and optional local context explanations.

The upcoming version will require an active **$3 USD/month subscription**. Sign-in and billing are being prepared; downloads and purchases are not open yet. This repository contains the website.

Requires Windows x64, the supported Stremio WebView2 desktop installation and Japanese subtitle text. Timing is estimated and context explanations can be wrong.
