Dictionary updating procedure (for rebuilding from source):
Download the latest JMdict XML from https://www.edrdg.org/jmdict/edict_doc.html
and use jamdict's documented import tool to create an updated jamdict.db.
Replace _internal/jamdict.db while the app is closed. The SQLite database must
use jamdict's schema. Reopen the app to load it. Keep EDRDG attribution and
the dictionary's license with any replacement database.
https://jamdict.readthedocs.io/
